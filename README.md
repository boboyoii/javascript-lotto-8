# 🎰 로또

우아한테크코스 8기 3주차 미션, 로또를 구현한 저장소입니다.

## 기능 요구사항 요약

- 로또 번호 범위: 1 ~ 45
- 당첨 정보
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 입력: 로또 구입 금액, 6개 로또 번호, 1개 보너스 번호
- 출력: 발행한 로또 수량 및 번호, 당첨 내역, 수익률

## 기능 목록

### 로또 구입

- [x] 사용자의 로또 구입 금액을 입력받는다.
  - 구입 금액이 비어 있지 않은지 확인한다.
  - 구입 금액이 숫자인지 확인한다.
  - 구입 금액이 양수인지 확인한다.
  - 구입 금액이 1,000원 단위인지 확인한다.
- [x] 구입 금액에 맞는 개수만큼 로또를 발행한다.
- [ ] 발행한 로또의 수량과 번호를 출력한다.

### 번호 입력

- [x] 당첨 번호를 입력받는다.
  - 입력한 번호가 6개인지 확인한다.
  - 각 번호가 비어 있지 않은지 확인한다.
  - 모든 값이 숫자인지 확인한다.
  - 모든 숫자가 1~45 범위 안에 있는지 확인한다.
  - 중복되는 숫자가 없는지 확인한다.
- [x] 보너스 번호를 입력받는다.
  - 값이 비어 있지 않은지 확인한다.
  - 숫자인지 확인한다.
  - 1~45 범위인지 검증한다.
  - 당첨번호와 중복되지 않는지 확인한다.

### 당첨 통계 계산 및 출력

- [ ] 사용자가 가진 모든 로또 번호를 당첨 번호와 하나씩 비교해 몇 개가 맞았는지 계산한다.
- [ ] 맞은 개수에 따라 등수를 결정해 저장한다.
- [ ] 등수별 당첨 내역을 출력한다.

### 수익률 계산 및 출력

- [ ] 총 상금과 구입 금액을 비교하여 수익률을 계산한다.
- [ ] 계산된 수익률을 소수점 첫째 자리까지 출력한다.

### 재입력

- [ ] 잘못된 입력이 들어올 경우 [ERROR] 메시지를 출력하고 해당 입력 단계를 다시 진행한다.
